The lost commit

A secret phrase is hidden in a repository history of 25,000 commits. Find it, and your name goes on the wall. Any language, any tools, no tricks needed. Just a correct algorithm.

The brief

  1. Read the history. Each c line is one commit: its hash, a time, its parents (comma-separated, - for none) and a one-character message, where _ means a space. The lines are in no particular order.
  2. Answer the queries. For each q a b line, find the merge base of a and b: a commit that is an ancestor of both (a commit counts as its own ancestor) and is not an ancestor of any other such common ancestor. If there is more than one, take the one with the latest time.
  3. Read the phrase. Write down each merge base's character, in query order. That phrase is your answer. 
# c <hash> <time> <parents> <char>
c 9c88f1 900 8b5d40,6f6a19 t
c 8b5d40 800 3c41d2 i
# q <a> <b>
q 6f6a19 7a13c7

Shortcuts like "the first shared commit I find" will give you a phrase that isn't one. Test your code on the sample first: its answer is printed at the bottom.
